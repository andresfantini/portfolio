El desafío

Una comunidad rural necesitaba supervisar a distancia las condiciones ambientales y del suelo de un invernadero, y controlar dispositivos de riego y ventilación. El desafío inicial consistía en integrar sensores, actuadores y sistemas de comunicación para posibilitar el monitoreo y control remoto. Posteriormente, el proyecto evolucionó hacia un segundo desafío: estructurar, validar y almacenar los datos para facilitar su análisis histórico.

Enfoque y contribución

El proyecto comenzó en 2023, durante una Diplomatura en Internet of Things de la UTN, mediante una experiencia colaborativa de desarrollo tecnológico para una comunidad rural. Posteriormente, retomé ese dominio para desarrollar una solución de Ingeniería de Datos con Python y PySpark.

  • Diseñé la arquitectura IoT con sensores DHT22, TSL2561 y capacitivos de humedad del suelo, ESP32, Raspberry Pi, MQTT/Mosquitto, Node-RED y Blynk; contemplé actuadores de riego y ventilación.
  • Modelé dispositivos, zonas y eventos de sensores y actuadores; preparé datos simulados y datos meteorológicos históricos externos para el procesamiento.
  • Implementé pipelines batch Bronze → Silver mediante Python y PySpark, con esquemas explícitos, lectores y escritores separados y validaciones de calidad por dataset.
  • Persistí los registros validados en Parquet; incorporé logging de ejecución y errores y documenté los módulos y secuencias del sistema.

Competencias demostradas

El proyecto combina comprensión de hardware y comunicaciones IoT con modelado de datos, procesamiento PySpark, validación de calidad, logging y organización modular del software. Demuestra una evolución técnica desde la adquisición y supervisión física hacia la preparación de datasets estructurados para análisis.

Evidencia y alcance

El repositorio documenta cinco pipelines Bronze → Silver desarrollados con Python y PySpark, con ejecuciones satisfactorias registradas durante el desarrollo y persistencia de datos en Parquet. Para probar el procesamiento se utilizaron eventos de sensores y actuadores, complementados con información meteorológica histórica externa. El proyecto cuenta además con documentación y diagramas de arquitectura.
