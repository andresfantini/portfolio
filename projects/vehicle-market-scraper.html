Vehicle Market Scraper

Extracción de publicaciones de vehículos mediante una arquitectura de software modular, evitando el acceso individual a cada publicación.

El desafío

Una concesionaria necesitaba analizar el mercado de vehículos usados, pero la extracción manual de publicaciones desde Mercado Libre resultaba inviable por el volumen y la paginación dinámica. El objetivo fue construir un scraper horizontal que capturara las tarjetas de resultados de forma masiva, normalizara los datos (precios, años, kilometraje) y evitara duplicados sin ingresar a cada publicación individual.

Enfoque y contribución

Diseñé el sistema como un flujo de procesamiento por etapas con responsabilidades separadas: 1. Adquisición HTTP: Sesión persistente, cookies y detección de bloqueos (403/429). 2. Paginación: Cálculo automático de las URLs de las páginas siguientes. 3. Crawler: Orquestador del recorrido que gestiona el límite de páginas y la deduplicación mediante identificadores únicos (IDs). 4. Parser: Interpretación del HTML de las tarjetas. 5. Normalización: Conversión de textos (ej. '130.000 Km') a valores numéricos listos para análisis. 6. Exportación: Generación del dataset en CSV. La validación inicial del MVP se realizó sobre una búsqueda de Volkswagen Up! 2018, obteniendo 106 registros con 0 duplicados.

Adquisición HTTP y paginación → Parsing y normalización → Deduplicación y exportación

Competencias demostradas

El proyecto demuestra capacidad para diseñar arquitecturas de software mantenibles (separando adquisición, parsing y exportación), aplicar técnicas de Web Scraping robustas frente a bloqueos, y desarrollar tests automatizados con fixtures HTML para garantizar la reproducibilidad del análisis sin depender del sitio en vivo.

Evidencia y alcance

El MVP se encuentra funcional y validado localmente. Se implementó un enfoque de scraping horizontal (solo páginas de resultados) para minimizar la carga sobre la plataforma. El scraping vertical (ingresar a cada aviso) queda fuera del alcance actual. El código incluye tests y documentación técnica de la arquitectura.
