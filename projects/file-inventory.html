El desafío

La gestión de grandes volúmenes de archivos dispersos en múltiples unidades de disco requiere una solución para catalogarlos. La búsqueda manual es ineficiente y dificulta el análisis del espacio de almacenamiento. El objetivo fue crear una herramienta que recorriera los discos, extrajera los metadatos (fechas, tamaño, ruta) y consolidara todo en un inventario analizable.

Enfoque y contribución

Desarrollé un flujo de trabajo dividido en dos etapas: 1. Sabueso (Bash): Un script interactivo que recorre las unidades seleccionadas, aplica filtros y genera archivos de texto (TSV) con los metadatos crudos y ordenados. 2. Procesamiento (Python): Un script que toma los resultados, los carga con Pandas, procesa las fechas y exporta un archivo Excel listo para su análisis. La arquitectura separa la recolección de datos (Bash) del procesamiento analítico (Python).

Exploración del sistema (Bash) → Extracción de metadatos → Procesamiento y Excel (Pandas)

Competencias demostradas

Este proyecto demuestra habilidades de automatización a nivel de sistema operativo, manejo de permisos (sudo), diseño de interfaces interactivas en terminal (Bash), y procesamiento analítico de datos con Pandas para generar reportes de valor.

Evidencia y alcance

El sistema es funcional y se encuentra en uso local. Se priorizó un enfoque de eficiencia mediante scripts y un manejo seguro de permisos elevados. El proyecto no incluye interfaz gráfica; su uso está orientado a la terminal.
