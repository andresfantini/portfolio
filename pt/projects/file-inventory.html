Busca recursiva de arquivos no sistema, extração de metadados e geração automática de relatórios estruturados em Excel.

O desafio

O gerenciamento de grandes volumes de arquivos dispersos em várias unidades de disco requer uma solução para catalogá-los. A busca manual é ineficiente e dificulta a análise do espaço de armazenamento. O objetivo era criar uma ferramenta que percorresse os discos, extraísse os metadados (datas, tamanho, caminho) e consolidasse tudo em um inventário analisável.

Abordagem e contribuição

Desenvolvi um fluxo de trabalho dividido em duas etapas: 1. Sabueso (Bash): Um script interativo que percorre as unidades selecionadas, aplica filtros e gera arquivos de texto (TSV) com os metadados brutos e ordenados. 2. Processamento (Python): Um script que pega os resultados, carrega-os com Pandas, processa as datas e exporta um arquivo Excel pronto para análise. A arquitetura separa a coleta de dados (Bash) do processamento analítico (Python).

Exploração do sistema (Bash) → Extração de metadados → Processamento e Excel (Pandas)

Competências demonstradas

Este projeto demonstra habilidades de automação no nível do sistema operacional, gerenciamento de permissões (sudo), design de interfaces interativas no terminal (Bash) e processamento analítico de dados com Pandas para gerar relatórios de valor.

Evidências e escopo

O sistema é funcional e encontra-se em uso local. Priorizou-se uma abordagem de eficiência por meio de scripts e um manuseio seguro de permissões elevadas. O projeto não inclui interface gráfica; seu uso é orientado ao terminal.
