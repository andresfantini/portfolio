File Inventory

Recursive file search across the system, metadata extraction, and automatic generation of structured Excel reports.

The challenge

Managing large volumes of scattered files across multiple disk drives requires a solution to catalog them. Manual searching is inefficient and makes it difficult to analyze storage space. The goal was to create a tool that would traverse the drives, extract metadata (dates, size, path), and consolidate everything into an analyzable inventory.

Approach & contribution

I developed a two-stage workflow: 1. Sabueso (Bash): An interactive script that traverses selected drives, applies filters, and generates text files (TSV) with raw and sorted metadata. 2. Processing (Python): A script that takes the results, loads them with Pandas, processes the dates, and exports an Excel file ready for analysis. The architecture separates data collection (Bash) from analytical processing (Python).

System exploration (Bash) → Metadata extraction → Processing & Excel (Pandas)

What this demonstrates

This project demonstrates operating system-level automation skills, permission management (sudo), interactive terminal interface design (Bash), and analytical data processing with Pandas to generate valuable reports.

Evidence & scope

The system is functional and in local use. An efficiency-focused approach was prioritized through scripts and secure handling of elevated permissions. The project does not include a graphical interface; its use is terminal-oriented.
